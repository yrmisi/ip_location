# IP Geolocation & Mapping Service

Веб-приложение на базе **FastAPI**, которое позволяет получать информацию о местоположении IP-адресов, кэшировать результаты в базе данных и генерировать интерактивные карты.

## Основные возможности

*   **Поиск геолокации**: Интеграция с внешним API для получения данных о стране, городе, провайдере и координатах по IP.
*   **Кэширование**: Сохранение данных об IP в PostgreSQL для снижения количества внешних запросов и повышения производительности.
*   **Интерактивные карты**: Генерация HTML-карт с помощью библиотеки `folium` на основе координат IP.
*   **Логирование запросов**: История запросов пользователей сохраняется в базе данных (IP, User-Agent, путь к сгенерированному файлу).
*   **Асинхронность**: Полностью асинхронная архитектура (FastAPI, SQLAlchemy, HTTPX).

## Технологический стек

*   **Backend**: Python 3.10+, FastAPI
*   **Database**: PostgreSQL + SQLAlchemy (Async)
*   **Configuration**: Pydantic (Settings Management)
*   **HTTP Client**: HTTPX
*   **Maps**: Folium (Leaflet.js)

## Установка и запуск

### 1. Предварительные требования
*   Python 3.10 или выше.
*   Установленный PostgreSQL.

### 2. Настройка окружения
Создайте файл `.env.postgres-prod` в директории `app/config/envs/` со следующими параметрами:
```env
POSTGRES_USER=your_user
POSTGRES_PASSWORD=your_password
POSTGRES_HOST=localhost
POSTGRES_PORT=5432
POSTGRES_DB=ip_location
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск приложения
```bash
uvicorn app.main:app --reload
```

## API Эндпоинты

### Geolocation Info
*   **URL**: `/ip_info`
*   **Метод**: `POST`
*   **Body**: `{"ip_address": "8.8.8.8"}`
*   **Описание**: Получает детальную информацию об IP и сохраняет в кэш.

### Map Generation
*   **URL**: `/map`
*   **Метод**: `GET`
*   **Параметры**: `ip` (string)
*   **Описание**: Генерирует интерактивную карту и возвращает HTML-файл.

### System Health
*   **URL**: `/health`
*   **Метод**: `GET`
*   **Описание**: Проверка работоспособности сервиса.

## Особенности реализации
*   Использование **uuid7** для генерации уникальных имен файлов карт.
*   Внедрение зависимостей через `AsyncSessionDep`.
*   Кастомные Favicon для генерируемых HTML страниц.
